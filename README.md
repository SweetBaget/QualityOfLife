# QualityOfLife

Небольшие утилиты, упрощающие повседневную работу за компьютером.

## Проекты

### [Быстрые заметки (QuickNotes)](QuickNotes/)

Лёгкая утилита для Windows: создание текстовых файлов в один клик.
Пользовательские кнопки (название + папка), имя файла по умолчанию — текущая
дата, окно редактирования с сохранением. PowerShell + WPF, без установки
и зависимостей. Подробности — в [QuickNotes/README.md](QuickNotes/README.md).
